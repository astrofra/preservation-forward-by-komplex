# Ground Truth Images

The images in this directory were generated in 2026 on a 2003 Power Mac G5.

They were recorded while running in Firefox and preserved as _ground truth_ screenshot captures.

> It is notable that the original Java demo seems to suffer from a few bugs, including a discrepancy in the intro sequence (_Mute95_) depending on the rendering resolution : when ran in half resolution, the particle cloud in the background saturates, which does not happen in full resolution.
